# Порядок работы над новой обсерваторией

1. Прочитать актуальную версию шаблона и инструкции. Начинать из этого репозитория,
   а не из живого сайта Ludoman и не из случайного старого архива.
2. Собрать карточку проекта: контракт, название, точность, репозиторий, проверенные
   пулы, источник логотипа, выбранный флаг, канал и дополнительные ссылки/метки.
   Для README каждого репозитория подготовить краткое описание проекта/токена:
   сверить контракт, изучить официальный сайт/документацию/связанный канал и
   метаданные. Сохранить текст, источники, дату и происхождение в
   project_description в project.json (см. docs/PROJECT_DESCRIPTIONS.md).
   Самоописание обозначать как заявление проекта; планы не выдавать за готовые
   функции. Если контракт или источники не установлены, явно указать пробел.
3. Проверить права репозитория/Actions и подключение к существующей инфраструктуре.
   Обнаруженные ограничения сообщить, продолжая независимую полезную работу.
4. Создать проект в пустом каталоге. Не переносить статистику, спецметки и адреса
   другого токена. Проверить источники и сохранить параметры в project.json.
5. Собрать и проверить HTML, размер и полноту данных. Проверить мобильную/настольную
   вёрстку, кнопки, ссылки, RU/EN, график, флаги, метки, раскрытие топа и переполнение.
6. Сохранить код, сверив новые изменения удалённой ветки. Не затереть другой коммит.
7. По согласованной схеме опубликовать именно проверенную версию. Указать commit
   и SHA-256 HTML, чтобы не перепутать файлы. Сохранить возможность отката.
8. Проверить ручной запуск и плановые обновления отдельно. Непроверенный плановый
   запуск не выдавать за работающий. Резервный исправный снимок не заменять пустотой.
9. В отчёте разделить: исходники сохранены / HTML проверен / сайт опубликован /
   автоматические обновления проверены. Назвать точные ограничения и недоступные разделы.

Цель — запуск нового проекта из токена и его параметров. Изменения общей логики
попадают в шаблон, особенности конкретного токена остаются только в его репозитории.
